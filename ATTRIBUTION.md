# Dataset Attribution

This checkpoint includes a self-contained copy of the core GTFS schedule tables derived from the public project:

**public-transport/sample-gtfs-feed**

https://github.com/public-transport/sample-gtfs-feed

The upstream project describes the dataset as an "imaginary GTFS data set used for testing" and publishes it under the ISC license.

GTFS specification:
https://gtfs.org/documentation/overview/
